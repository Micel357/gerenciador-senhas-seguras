# Testes

Os testes automatizados Java/JUnit ficam em `src/test/java` e podem ser executados com `mvn test`. Eles cobrem política e geração de senhas, cifra/decifra do cofre, operações CRUD, busca, backup/restauração e autenticação/uso da API.

A coleção Postman em `postman/` é um complemento manual para a API; ela não é exigida para compilar, executar ou validar os testes JUnit.
